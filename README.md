# Game Dev Tracker

A local production board for one game. Track the title, target date, milestones, and tasks across code, art, design, and audio.

## Open it

Open `index.html` in a browser. No install or server is required.

The first visit loads a sample game, **Cinderwake**, so the board is not empty. Rename it, or choose **Start fresh** for a blank project. **Load sample game** brings the sample back.

## What you can track

- Game title, logline, and target date, with days left and an overall percent finished
- Progress for Code, Art, Design, and Audio
- Milestones with optional dates
- Tasks on a To do / In progress / Done board

Click a discipline or milestone to filter the board. Click a task title to rename it.

## Saving

The board is stored in this browser on this computer (`localStorage`). Reloading the page keeps your progress. Clearing site data, or opening the file in another browser, starts from the saved data in that browser only.
